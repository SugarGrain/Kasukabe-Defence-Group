
# Lost and Found Management System

A web application for reporting and recovering lost items.

## Technology Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB

## Team Features
1. User Authentication
2. Lost Item Management
3. Found Item Management
4. Search and Matching
5. Claim and Recovery

## Project Management
Jira Scrum - 4 Weekly Sprints
